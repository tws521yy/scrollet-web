裝置上處理

續圖透過 Apple ReplayKit 擷取螢幕畫面，用於產生長截圖。圖片拼接及基於 Apple Vision 的文字辨識在裝置上完成。我們不會把截圖或辨識文字傳送至開發者營運的伺服器。續圖不處理或儲存麥克風音訊。

暫存畫面與匯出結果

擷取的原圖和工作階段資訊暫存於 App 與錄製擴充功能共用的裝置容器中。開始新錄製時會清除上一輪素材。正常重新開啟 App 時會清理未使用中的素材；仍在進行的錄製或透過完成入口明確開啟的素材會保留。你主動儲存至照片或分享出去的圖片由所選目的地保存，不會被此清理操作刪除。

免費額度與設定

設定及免費使用記錄儲存於裝置上。額度記錄包含目前額度週期、次數及用於避免重複扣次的結果指紋；它儲存在僅限目前裝置、不參與同步的鑰匙圈中，移除並重新安裝後可能仍然保留。我們不上傳此記錄，也不將它用於跨 App 或跨網站追蹤。

購買與訂閱

訂閱和永久買斷由 Apple 透過 StoreKit 處理。續圖在裝置上檢查經過驗證的交易資訊，以判斷 Pro 功能的使用權限。我們不會取得你的銀行卡或付款卡資料。付款、續訂、退款及交易記錄由 Apple 依照其條款與隱私權政策處理。

權限與分享

螢幕擷取僅在你透過系統介面開始錄製後進行。儲存結果時，續圖請求向照片加入圖片的權限，不請求讀取整個照片圖庫。複製和分享由你主動操作；分享後的內容由目標 App 或服務依照其政策處理。匯出至照片的圖片也可能依照你自己的 iCloud 照片設定同步。

統計與廣告

續圖不包含廣告 SDK、第三方行為統計或跨 App 廣告追蹤。裝置上的診斷檔案不會自動上傳給我們。Apple 服務獨立收集的資料由 Apple 的政策管理。

本網站與技術支援

本網站使用 GitHub Pages 託管。GitHub 會出於安全目的記錄訪客的 IP 位址。網站不另外加入統計指令碼、廣告追蹤、Cookie 或聯絡表單。技術支援使用 GitHub Issues：提交回報需要 GitHub 帳號，你的 GitHub 使用者名稱和提交內容公開可見。開發者使用你主動提供的資訊回覆請求。請勿發布密碼、付款資料、包含私人資訊的截圖或其他敏感內容。GitHub 依照其隱私權聲明處理你的帳號和網站存取活動。

你的選擇與政策更新

你可以透過系統錄製標記停止擷取，在照片中刪除已儲存的圖片，在分享目的地管理副本，並在 Apple 帳號中管理或取消訂閱。續圖的資料處理方式變更時，本政策會更新；上方日期標示目前版本。有關隱私的問題可聯絡開發者。

聯絡我們

如需技術支援或有隱私相關問題，請聯絡開發者： GitHub Issues

透過 GitHub 回報問題

GitHub 回報內容公開可見，需要 GitHub 帳號。請勿提交私人資訊。

請提供 iOS 版本、續圖版本和問題的簡短說明。請勿寄送密碼、付款資料或包含私人資訊的截圖。
