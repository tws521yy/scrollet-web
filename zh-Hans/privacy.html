本机处理

续图通过 Apple ReplayKit 捕获屏幕画面，用于生成长截图。图片拼接及基于 Apple Vision 的文字识别在设备上完成。我们不会把截图或识别文字发送到开发者运营的服务器。续图不处理或保存麦克风音频。

临时画面与导出结果

捕获的原图和会话信息临时保存在 App 与录屏扩展共用的本机容器中。开始新录屏时会清除上一轮素材。正常重新打开 App 时会清理不活跃的素材；仍在进行的录屏或通过完成入口明确打开的素材会保留。你主动保存到相册或分享出去的图片由所选目的地保存，不会被此清理操作删除。

免费额度与设置

设置及免费使用记录保存在本机。额度记录包含当前额度周期、次数及用于避免重复扣次的结果指纹；它存储在仅限当前设备、不参与同步的钥匙串中，卸载重装后可能仍然保留。我们不上传此记录，也不将它用于跨 App 或跨网站跟踪。

购买与订阅

订阅和永久买断由 Apple 通过 StoreKit 处理。续图在本机检查经过验证的交易信息，以判断 Pro 功能的使用权限。我们不会获得你的银行卡或支付卡资料。付款、续订、退款及交易记录由 Apple 依照其条款与隐私政策处理。

权限与分享

屏幕采集仅在你通过系统界面开始录屏后进行。保存结果时，续图请求向相册添加图片的权限，不请求读取整个相册。复制和分享由你主动操作；分享后的内容由目标 App 或服务依照其政策处理。导出到相册的图片也可能根据你自己的 iCloud 照片设置同步。

统计与广告

续图不包含广告 SDK、第三方行为统计或跨 App 广告跟踪。本机诊断文件不会自动上传给我们。Apple 服务独立收集的数据由 Apple 的政策管理。

本网站与技术支持

本网站使用 GitHub Pages 托管。GitHub 会出于安全目的记录访问者的 IP 地址。网站不另外加入统计脚本、广告跟踪、Cookie 或联系表单。技术支持使用 GitHub Issues：提交反馈需要 GitHub 账号，你的 GitHub 用户名和提交内容公开可见。开发者使用你主动提供的信息回复请求。请勿发布密码、支付资料、包含私人信息的截图或其他敏感内容。GitHub 依照其隐私声明处理你的账号和网站访问活动。

你的选择与政策更新

你可以通过系统录屏标记停止采集，在相册中删除已保存的图片，在分享目的地管理副本，并在 Apple 账户中管理或取消订阅。续图的数据处理方式变化时，本政策会更新；上方日期标明当前版本。有关隐私的问题可联系开发者。
