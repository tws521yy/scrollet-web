端末上での処理

Scrollet は Apple ReplayKit を使って画面をキャプチャし、縦長のスクリーンショットを生成します。画像の結合と Apple Vision による文字認識は端末上で実行されます。スクリーンショットや認識した文字を開発者のサーバーへ送信することはありません。Scrollet はマイクの音声を処理・保存しません。

一時ファイルと書き出した画像

キャプチャした元画像とセッション情報は、アプリと録画拡張が共有する端末内の領域に一時保存されます。新しい録画を始めると、前回の素材が削除されます。通常のアプリ再起動時には使用中でない素材を削除しますが、進行中の録画や完了時の入口から明示的に開いた素材は保持します。写真に保存した画像や共有先に送った画像は、この削除処理の対象ではありません。

無料利用回数と設定

設定と無料利用記録は端末内に保存されます。利用記録には現在の期間、回数、同じ結果を二重に数えないための指紋情報が含まれます。記録は同期しない端末専用のキーチェーンに保存され、アンインストール後の再インストールでも残る場合があります。当方はこの記録をアップロードせず、他のアプリやウェブサイトをまたぐ追跡にも使用しません。

購入とサブスクリプション

サブスクリプションと買い切りは、Apple が StoreKit を通じて処理します。Scrollet は端末上で検証済みの取引情報を確認し、Pro 機能へのアクセスを判断します。当方がカード情報や銀行口座情報を受け取ることはありません。支払い、更新、返金、取引記録は Apple の規約とプライバシーポリシーに従って処理されます。

アクセス許可と共有

画面のキャプチャは、システム画面から録画を開始した場合にのみ行われます。画像保存時には写真への追加権限を求めますが、写真ライブラリ全体の読み取り権限は求めません。コピーや共有はユーザーの操作により実行されます。共有後の内容は送信先のアプリやサービスのポリシーに従います。写真へ保存した画像は、ご自身の iCloud 写真の設定により同期される場合もあります。

分析と広告

Scrollet には広告 SDK、第三者の行動分析、アプリ間の広告トラッキングを組み込んでいません。端末内の診断ファイルが当方へ自動送信されることはありません。Apple のサービスが独立して収集するデータには Apple のポリシーが適用されます。

このウェブサイトとサポート

本サイトは GitHub Pages でホストされています。GitHub はセキュリティ目的で訪問者の IP アドレスを記録します。本サイト独自の分析スクリプト、広告トラッカー、Cookie、問い合わせフォームはありません。サポートには GitHub Issues を使用します。投稿には GitHub アカウントが必要で、ユーザー名と投稿内容は公開されます。開発者は提供された情報を回答のために使用します。パスワード、支払い情報、個人情報を含む画像やその他の機密情報は投稿しないでください。アカウントやサイトへのアクセス情報は GitHub のプライバシー声明に従って処理されます。

ユーザーの選択と更新

システムの録画表示からキャプチャを停止でき、写真に保存した画像や共有先のコピーをご自身で削除・管理できます。サブスクリプションは Apple アカウントで管理・解約できます。データの取り扱いを変更する場合は本ポリシーを更新し、上部の日付で最新版を示します。プライバシーに関するご質問は開発者へお問い合わせください。
